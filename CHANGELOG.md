# Changelog

Each release has a short section in Spanish first, then English. The Spanish
section is what the user hears before an update is installed, so keep it short,
concrete and free of jargon.

## Unreleased

**Español.** Primera versión. El botón tiene dos gestos: pulsar para hablar y
para parar, mantener pulsado para cancelar. Dictado, Claude Code, respuesta
hablada sin leer código ni fórmulas símbolo a símbolo. Actualización por voz
con confirmación, y deshacer. Pizarra de matemáticas en el navegador, que
funciona sin internet. Funciona en Windows, macOS y Linux.

**English.** First version. Two gestures on one button: press to talk and to
stop, hold to cancel. Dictation, Claude Code, spoken replies that do not read
code or formulas symbol by symbol. Voice update with confirmation, and undo.
Maths blackboard in the browser, working offline. Runs on Windows, macOS and
Linux.
